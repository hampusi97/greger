# greger (static demo)

Lightweight single-file HTML demo of VelvetMotion-style AI companions (chat + NSFW image/video generation via Pollinations).

**The full product lives here:**

→ **https://github.com/hampusi97/velvetmotion-ai**

That repo is the combined Next.js app with:

- 8 original adult companions
- Free chat (Pollinations + local fallback + optional xAI/OpenAI keys)
- Portrait / lingerie / nude / explicit / sex-video generation
- Coin economy + persistent on-device gallery
- JOI packs, story packs, TTS

## This repo

`index.html` is a self-contained static demo (age gate, companions, chat, generate panel, coins). Open it in a browser or host on GitHub Pages / Netlify / Vercel static.

For production features, coins that survive deploys, real LLM keys, and the full UI, use **velvetmotion-ai**.
