# greger# VelvetMotion

A seductive AI companion website inspired by Candy.ai and other premium platforms.

## Features
- 180+ AI companions (including duos)
- Login system (remembers your name)
- Create custom girls from photo or Instagram
- Chat with personality-driven replies (free & unlimited)
- Advanced media generation (image & video)
- Tinder-style roleplay
- Private gallery
- Coins system (only generation costs coins)

## Tech
- Single-file HTML (easy to deploy)
- Fully responsive
- Dark, premium Candy.ai-style design

## Deployment
This project is optimized for **Vercel**.

### Deploy to Vercel
1. Push this repo to GitHub
2. Import the repo on [vercel.com](https://vercel.com)
3. Deploy

## Local Use
Just open `index.html` in any browser.
